5 - Adicionando um Novo Atributo a um Elemento

Considere o seguinte XML:

<catalogo> 
  <produto id="A45"> 
    <nome>Caneta Azul</nome> 
    <preco>2.50</preco> 
    <estoque>150</estoque> 
  </produto> 
</catalogo>

Escreva um script JavaScript que:

  • Parseie a string XML.
  • Encontre o elemento <produto id="A45">.
  • Adicione um novo atributo chamado moeda com o valor BRL.
  • Exiba no console o valor do novo atributo usando getAttribute('moeda').

Resultado no Console:

Abra o console (F12 → aba Console) para verificar o valor do novo atributo.

"Atributo 'moeda' adicionado: BRL"
