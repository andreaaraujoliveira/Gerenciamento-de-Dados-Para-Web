4 - Alterando o Valor de um Nó de Texto

Considere o seguinte XML:

<catalogo> 
  <produto id="A45"> 
    <nome>Caneta Azul</nome> 
    <preco>2.50</preco> 
    <estoque>150</estoque> 
  </produto> 
</catalogo>

Escreva um script JavaScript que:

  • Parseie a string XML acima para criar um xmlDoc.
  • Encontre o elemento <preco> dentro do <produto> com id="A45".
  • Altere o valor do nó de texto (nodeValue do firstChild) do elemento <preco> para 3.00.
  • Acesse e exiba no console o novo valor para confirmar a alteração.

Resultado no Console:

Abra o console (F12 → aba Console) para ver o novo valor do preço.

"Novo valor do preço: 3.00"
